# 💰 SpendWise – Personal Finance & Expense Management Platform

SpendWise is a full-stack personal finance and expense management application designed to help users manage their daily finances efficiently. It allows users to track income, expenses, monitor monthly budgets, and analyze spending habits through an interactive dashboard.

## 🚀 Features

- User Registration and Login
- Secure Authentication using JWT
- User Authorization using Spring Security
- Add, Update, Delete and View Transactions
- Income and Expense Tracking
- Category-wise Expense Management
- Monthly Budget Management
- Interactive Financial Dashboard
- Spending Pattern Visualization
- Monthly Income and Expense Summary
- Filter Transactions by Date, Category and Type
- Export Transactions to CSV

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/spendwise-personal-finance-management.git
```

### 2. Backend Setup

- Open the backend folder in IntelliJ IDEA.
- Configure your MySQL database.
- Update database credentials in application.properties.
- Run the Spring Boot application.

### 3. Frontend Setup

```bash
cd frontend
npm install
npm start
```
